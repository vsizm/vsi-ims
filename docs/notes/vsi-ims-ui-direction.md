# VSI IMS UI Direction

VSI IMS should use a compact, card-led operating interface inspired by executive dashboard layouts.

## Principles

- Keep the interface focused on the governed delivery hierarchy.
- Use compact metric cards for high-value status and summary information.
- Use clear action cards for Directorates, Programmes, Projects and Activities.
- Preserve VSI colours: Yale Blue `#094074`, Baltic Blue `#3c6997`, Regal Navy `#003566`, and the existing VSI yellow accent.
- Avoid decorative charts or widgets that do not support a management decision.
- Keep Programmes and CPRM visually primary; enabling functions should remain visually secondary.

The attached construction-dashboard reference is used only as a visual interaction reference. VSI IMS does not copy its branding, content or construction-specific terminology.
