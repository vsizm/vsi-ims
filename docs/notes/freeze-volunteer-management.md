# Volunteer Management Freeze

Volunteer Management is temporarily frozen in the active VSI IMS operating surface.

The existing volunteer data model and API routes are retained for data integrity and future reactivation, but Volunteer Management is not part of the active V1 navigation or delivery workflow.

The active V1 focus remains:

- Programmes and CPRM as the two core organisational engines.
- MEAL, Finance/Admin, PAR, Legal/Compliance and Operations as enabling/support functions.
- Directorate → Programme → Project → Activity as the authoritative delivery hierarchy.

When Volunteer Management is reactivated, it should be reintroduced deliberately rather than through the current sidebar sprawl.
