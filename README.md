# VSI IMS

Visionary Students Initiative Information Management System.

## Purpose
VSI IMS provides one governed operational workspace for programmes, projects, activities, reporting, financial intelligence, volunteer management and verified beneficiary reach.

## Operating model

**Programme → Project → Activity → Delivery → Reporting → Results**

Volunteer delivery is connected to the same operational records rather than maintained as a separate reporting universe.

## Core principles

- One authoritative record for each business entity.
- Development, staging/acceptance and production environments remain separated.
- Access is role- and permission-controlled.
- Operational changes are attributable and auditable.
- Financial intelligence is expressed in **ZMW**.
- The programme reach objective is **100,000 verified beneficiaries**; progress is only counted from authoritative beneficiary records.
- VSI corporate typography uses **Roboto**.
- The interface is intentionally restrained: one primary management dashboard, focused workspaces and no unnecessary dashboard proliferation.

## Delivery

Pull requests targeting `staging` are used for acceptance testing. Production release should only follow acceptance of the staging deployment.
